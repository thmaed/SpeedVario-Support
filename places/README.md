# Offline place names — data files

These files are the place names that **Speed Vario** shows on its offline basemap: villages,
hamlets, peaks and passes, cut into squares of 1° of latitude and longitude
(`v1/<latitude>/<longitude>.bin`, raw‑DEFLATE compressed). The app downloads the squares around the
user's position while it has a connection, so the map can still name places once it has none.
Cities, towns and well‑known peaks are bundled in the app itself.
