# Speed Vario — support and privacy

The public pages of the Speed Vario app, served by GitHub Pages:

- Support: https://thmaed.github.io/SpeedVario-Support/
- Privacy policy: https://thmaed.github.io/SpeedVario-Support/privacy

The app's source lives in a private repository; this one holds only these two pages.

**Single source of truth.** `privacy.md` is generated from `Appstore/wiki_Home.md` in the app
repository — edit it there, then regenerate, so the policy shipped to the App Store and the one
published here can never disagree.
